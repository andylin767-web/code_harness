# Python Programs

This repository contains two simple Python programs.

## Programs

### 1. Hello World (`hello_world.py`)

A simple program that prints "Hello, World!" to the console.

**Usage:**
```bash
python hello_world.py
```

**Expected Output:**
```
Hello, World!
```

### 2. Calculator (`calculator.py`)

An interactive calculator program that supports basic arithmetic operations: addition, subtraction, multiplication, and division.

**Usage:**
```bash
python calculator.py
```

**Supported Operations:**
- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division

**Example Session:**
```
Simple Calculator
Operations: +, -, *, /
Type 'quit' to exit

Enter expression (e.g., 5 + 3): 10 + 5
Result: 15.0
Enter expression (e.g., 5 + 3): 20 / 4
Result: 5.0
Enter expression (e.g., 5 + 3): quit
Goodbye!
```

## Requirements

- Python 3.6 or higher
